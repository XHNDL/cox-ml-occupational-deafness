# 融合 Cox 模型与机械学习的职业性耳聋患病预测研究

本项目将**传统 Cox 比例风险生存模型**与**机器学习算法**相融合，构建职业性噪声聋（职业性耳聋）患病风险预测系统，用于挖掘噪声作业人群的患病危险因素并实现个体发病风险的量化预判。

---

## 一、研究背景

据 WHO《世界听力报告》，全球超过 **15 亿人**存在听力受损，其中工作场所职业性噪声危害导致的听力损失占全部听力损失的 **16.0%**。我国正处于快速发展的工业期，暴露于职业性噪声的劳动者数量持续增加，**职业性噪声聋已成为继尘肺病之后的我国第二大职业病**。

该病具有三个显著特点：

- **发病隐匿** —— 早期听力损伤缺乏自觉症状，易被劳动者忽视
- **损伤不可逆** —— 一旦形成听力损失，现有临床手段无法逆转
- **治疗手段有限** —— 医学干预空间小，防控重心必须前移

因此，**早期预警与科学预防**成为职业性耳聋防控工作的核心关键。

### 为什么需要融合建模

两类方法各有其固有缺陷，恰好互补：

| 方法 | 优势 | 固有缺陷 |
|---|---|---|
| Cox 比例风险模型 | 能处理**时间-事件**关系，具备生存分析解释性，输出风险比（HR） | 难以刻画**非线性**关系 |
| 机器学习模型 | 拟合能力强，能捕捉复杂非线性特征交互 | 缺乏对**时间因素**的解释性 |

融合二者，可以在保留生存分析时间维度解释力的同时，提升非线性预测精度。

## 二、方法框架

### 2.1 建模流程

```
                     原始体检数据
            ┌──────────────┴──────────────┐
        数据2.xlsx                    数据3（有听力）.xlsx
     （职业病人群）                    （含听力阈值人群）
            │                              │
            │  标签：疑似职业病/确诊           │  标签：双耳高频平均听阈 > 25 dB
            └──────────────┬───────────────┘
                           ▼
                   data_clear.py
              字段提取 · 工龄解析 · 异常值清洗 · 中位数填充
                           ▼
                  result/unified_data.csv
                           ▼
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
  cox_ml_unified.py   factor_analysis.py   trend_analysis.py
   Cox + ML 融合预测       因素关联分析          职业病趋势分析
```

### 2.2 Cox 比例风险模型

使用 `lifelines.CoxPHFitter` 拟合，参数设定：

- **时间变量（duration）**：`接害工龄_年`，上限截断至 30 年
- **事件变量（event）**：`target_noise`（双耳高频平均听阈 > 25 dB 判定为阳性）
- **协变量**：性别、年龄、身高、体重、BMI、收缩压、舒张压
- **建模要点**：刻意**将「接害工龄」排除出协变量**，因其与时间变量高度共线

输出各因素的风险比（HR）、95% 置信区间与 P 值，并按 `|ln(HR)|` 归一化为特征权重（P > 0.1 的变量权重折半）。

### 2.3 机器学习模型

对特征做 `StandardScaler` 标准化后，以 7:3 分层划分训练/测试集，并行训练三个模型：

- Logistic Regression
- Random Forest（n_estimators=150, max_depth=10）
- Gradient Boosting（n_estimators=100, max_depth=5）

以测试集 AUC 选优。

### 2.4 融合策略

当前采用**简单加权平均**：Cox 风险分数经 sigmoid 归一化后，与最优 ML 模型预测概率各取 **50%** 权重融合。

```
combined_proba = 0.5 × ML_概率 + 0.5 × (1 - Cox_sigmoid_风险分数)
```

## 四、数据说明

### 4.1 数据集概况

| 数据集 | 样本量 | 标签定义 | 阳性数（率） |
|---|---|---|---|
| 数据3（有听力） | 46,267 | 双耳高频平均听阈 > 25 dB | 13,361（28.9%） |
| 数据2 | 76,035 | 疑似职业病 / 职业病确诊 | 22（0.03%） |
| 合并统一数据集 | 122,302 | — | — |
| 职业病报告数据 | 约 810 例 | 2024 年报告病例 | 噪声聋 239 例、尘肺病 379 例 |

### 4.2 特征字段

模型使用的 8 个特征：

| 字段 | 说明 | 清洗合理区间 |
|---|---|---|
| `性别` | 男=1，女=0 | — |
| `年龄` | 岁 | — |
| `接害工龄_年` | 接触噪声作业工龄，支持「X年Y月」格式解析 | — |
| `身高_cm` | 厘米 | 100–220 |
| `体重_kg` | 千克 | 30–200 |
| `BMI` | 体质指数 | 10–60 |
| `收缩压_mmHg` | 收缩压 | 60–200 |
| `舒张压_mmHg` | 舒张压 | 40–130 |

### 4.3 清洗规则

- **工龄解析**：正则提取「N 年 M 月」并折算为 `N + M/12`
- **异常值处理**：超出上表合理区间的值置为缺失（NaN）
- **幻影值清除**：`999`、`999.0`、`999.9`、`inf` 统一置为 NaN
- **缺失值填充**：建模前以各列**中位数**填充
- **额外派生**：肺功能（30–150）、心电图异常、胸片异常

## 五、运行方式

### 5.1 环境依赖

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn lifelines joblib openpyxl
```

> 绘图字体依赖 `SimHei` / `Microsoft YaHei` / `SimSun`，Windows 环境开箱可用；Linux/macOS 需自行安装中文字体。

### 5.2 执行顺序

**所有脚本均使用相对路径，必须在项目根目录下运行。**

```bash
# ① 数据清洗，生成 result/unified_data.csv
python data_clear.py

# ② 因素关联分析，输出 unified_factor_analysis.png
python factor_analysis.py

# ③ Cox + ML 融合建模，输出 cox_ml_unified_results.png 及 models_cox_ml/
python cox_ml_unified.py

# ④ 职业病趋势分析，输出 occupation_disease_trend.png
python trend_analysis.py
```

> 注意：`cox_ml_unified.py` 与 `factor_analysis.py` 依赖 ① 生成的 `result/unified_data.csv`；`trend_analysis.py` 直接读取 `data/` 下的 Excel，与其他脚本相互独立。

## 六、结果与指标

### 6.1 模型性能

| 模型 | AUC | 说明 |
|---|---|---|
| Cox 比例风险模型 | 0.435 | 一致性指数（concordance）= 0.556 |
| 机器学习（Gradient Boosting） | **0.669** | 三者中最优 |
| 融合模型（50/50 加权） | 0.573 | 介于两者之间 |

### 6.2 主要发现

- **年龄**与患病风险相关性最强
- **接害工龄**越长，发病风险越高
- **BMI** 呈中度相关
- **血压**相关性较弱
- 数据2 中**肺功能**是值得注意的风险因素

### 6.3 结果图

| 图片 | 内容 |
|---|---|
| `cox_ml_unified_results.png` | Cox 森林图、ROC 曲线对比、模型 AUC 对比、Kaplan-Meier 生存曲线、RF 特征重要性、Cox vs RF 特征重要性、预测概率分布、Cox 风险分数分布 |
| `unified_factor_analysis.png` | 按年龄/工龄/BMI/性别/血压分层的发病率、肺功能与职业病风险、相关性热力图 |
| `occupation_disease_trend.png` | 噪声聋年度病例数、职业病类型分布对比 |

## 七、已知局限与待改进

本项目如实记录当前版本存在的问题，供后续迭代参考：

1. **融合反而降低了性能** —— 融合模型 AUC（0.573）低于单一 ML 模型（0.669），说明当前 50/50 等权融合策略不合理。后续应改为按验证集 AUC 或交叉验证结果自适应赋权，或采用 stacking 方式融合。
2. **Cox 模型区分度不足** —— Cox AUC 仅 0.435（低于随机水平 0.5），concordance 0.556 也偏低。原因可能在于：协变量中剔除了与时间强相关的接害工龄、连续变量未做非线性变换（如样条）、比例风险（PH）假定未做检验。
3. **数据2 极端类别不平衡** —— 阳性仅 22/76,035（0.03%），直接用 AUC 评估会严重失真，需引入 SMOTE、类别权重或改用 PR-AUC 等指标。当前主模型实际只使用了数据3。
4. **趋势数据名不副实** —— `2020-2024年职业病新发报告时间.xlsx` 实际仅包含 **2024 年**报告病例，无法进行多年趋势分析，文件名与内容不符。
5. **两数据集标签口径不一致** —— 数据2 用「疑似/确诊职业病」、数据3 用「听阈 > 25 dB」，合并后无法直接联合建模，目前仅是拼接存储。
6. **缺少外部验证** —— 尚无独立验证集或时间外推验证，模型的泛化能力有待检验。
7. **模型文件为 pickle 格式** —— `models_cox_ml/*.pkl` 通过 `joblib`/`pickle` 序列化，加载不受信任的 pickle 文件存在反序列化执行代码的安全风险，仅建议加载本仓库自行生成的模型。
